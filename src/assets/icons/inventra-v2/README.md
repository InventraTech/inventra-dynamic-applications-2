# Ícones Inventra

Esta pasta guarda os SVGs locais do conjunto **Ícones Inventra v2** no Figma. O arquivo continua em andamento; quando novos ícones forem finalizados, adicione o SVG aqui e registre-o em `index.ts` com um nome em camelCase.

Fonte: [Ícones Inventra v2 no Figma](https://www.figma.com/design/iExueGDdOdbvjxl5cyb0ds/Inventra---2%C2%BA-Ano?node-id=832-9).

O registro `inventraIcons` centraliza os assets para reutilização sem referências a URLs temporárias do Figma. Os três ícones da tela de cadastro também ficam aqui com prefixo `register`. Preserve as dimensões intrínsecas e o conteúdo dos SVGs ao usá-los.
